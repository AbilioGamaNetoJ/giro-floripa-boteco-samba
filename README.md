# Roleta Premiada — Giro Floripa

Landing da campanha: o visitante gira a roleta, vê o prêmio e preenche nome + WhatsApp para receber um cupom na tela.

```sh
npm install
npm run dev
```

O cupom do MVP é gerado no navegador (`localStorage`). Limpar o aparelho permite girar de novo. Persistência real (API + banco + validação no balcão) fica para a fase 2.
